Florence Masetla — Portfolio Website
A responsive, single-page portfolio for learning design, eLearning development, course management and technology education. Built with plain HTML, CSS and JavaScript so it is simple to upload to GitHub and publish with GitHub Pages.

Before publishing
Open index.html.
Replace YOUR_EMAIL@example.com with your professional email address.
Replace the LinkedIn link (https://www.linkedin.com/) with your actual profile URL.
Review the career timeline, project summaries and qualifications. Adjust any wording or dates you want to present differently.
Add real project screenshots or downloadable work samples only when you have permission to share them.
Publish with GitHub Pages
Sign in to GitHub and create a new repository, for example florence-portfolio.
Upload index.html, style.css, script.js and README.md to the repository's root (the top level).
Open the repository's Settings → Pages.
Under Build and deployment, choose Deploy from a branch.
Select the main branch and / (root) folder, then save.
Wait a few minutes. GitHub will show the public website URL in the Pages section.
Local preview
Open index.html in a browser. The site uses Google Fonts when an internet connection is available; system fallback fonts are included.
